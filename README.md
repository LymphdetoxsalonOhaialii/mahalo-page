# Mahalo from ohaialii

Lymph detox salon ohaialii のGoogle口コミ案内ページです。

## GitHub Pages 公開手順
1. GitHubで `mahalo-page` という新しいPublicリポジトリを作成
2. このフォルダ内の `index.html`, `style.css`, `script.js`, `images/logo.jpg` をアップロード
3. Settings → Pages → Source を `Deploy from a branch`
4. Branch を `main` / `/ (root)` にして Save
5. 数分後、次のURLで公開できます：
   https://LymphdetoxsalonOhaialii.github.io/mahalo-page/
